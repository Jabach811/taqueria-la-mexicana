# Taqueria La Mexicana — Redesign Concept

A presentation-ready static redesign concept for Taqueria La Mexicana: a family-run Tracy-area taqueria since 1994.

## Includes

- Food-led landing page
- Full, organized menu page
- Three-location ordering flow
- Catering inquiry concept
- Responsive mobile layout

This repository is a design pitch and not the restaurant's official production website.
